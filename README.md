# Big Data Competition

这里是这个项目的介绍。
这个项目的根目录一共有7个文件。
.gitattributes和本文件没啥用，不过前者别乱改。
.gitignore是用来向仓库声明哪些文件不要传上去的，具体内容在这个文件里头。
还有四个文件夹：
    1.backup是用来做缓冲用的。因为github我也不会用🤪，所以我经常把自己的修改覆盖掉，重新找很麻烦。如果你对某一次拉取（提交无所谓，github会视奸你的一举一动）不确定的话就把文件先复制到这个文件夹里。为避免互相复制冲突，这个文件夹在不改动gitignore的情况下不会被上传（hub上应该是个空文件夹）
    2.private是用来放一些还未检查的活的，比如大肥鱼的成果之类的，放在这里可以避免往hub上搬史污染数据库。同样的，在不改动gitignore的情况下不会被上传（hub上应该是个空文件夹）
    3.resources我把附件和题目全放进去了。
    4.work是自己写的东西，一开始是大肥鱼成果，后面要逐步替换
