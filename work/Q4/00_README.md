## 一、30 秒结论

| 指标 | 数值 |
|---|---|
| 影响面积 | **1.37 km²** |
| 最大水深 | **13.0 m**（5–7 km 窄段） |
| 域内存储体积 | **6.20 × 10⁶ m³**（V₀ 的 83%，18% 从下游出口流出） |
| 口岸台地 | **不在淹没范围内**（高出沟底 104 m） |
| 沟道内到达时间 | 0 – **17.0 分钟** |
| 沟道长度 / 落差 | 20.7 km / 1871 m |
| 视摩擦角 μ_E | 0.0905（5.2°） |
| Voellmy μ | 0.0057（ξ=1000、h=8） |

**一句话**：碎屑流沿 20.7 km 沟道运移、17 分钟抵达口岸段；但口岸台地高出沟底 104 m，模型判定其不被淹没——若实际灾害发生在台地，需要额外的漫流/改道解释。

## 三、复现

环境：Python 3.12，依赖 `numpy pandas rasterio scikit-learn matplotlib`。

```bash
cd Q4
python code/p4_sim.py      # 约 1 分钟（KDTree + 6 次掩膜迭代）
python code/p4_figs.py     # 几秒，出图 1–3
python code/p4_process.py  # 几秒，出图 4–6
```

DEM 读 `../resources/dem/DEM.tif`。

敏感性：`P4_V0=2500000 python code/p4_sim.py` 可改体积（需重跑出图）。

## 五、必须写进论文的局限

1. **面积随体积缓慢变化**：体积 2.5→12.5 ×10⁶ m³，面积 1.24→1.54 km²（+24%），水深 5.3→21.1 m。
2. **体积守恒是分段成立的**：域内 83%，其余 18% 从 20.7 km 处的下游出口流出，未模拟域外堆积。
3. **口岸台地不被淹没**：与"口岸重大伤亡"存在张力，需讨论漫流/改道/堤防溃决等 DEM 无法表达的因素。
4. 能量线法不含流速场与冲击力，不能用于承灾体损失评估。
5. 未建模沿途松散物质汇入，也未建模堰塞湖溃决。
6. 30 m DEM 低估沟道深度。
