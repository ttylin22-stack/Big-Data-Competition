## 一、30 秒结论

| 指标 | 数值 |
|---|---|
| 影响面积 | **1.71 km²** |
| 最大水深 | **10.4 m**（源区） |
| 口岸台地 | **不在淹没范围内**（高出沟底 104 m） |
| 沟道内到达时间 | 0 – **17.0 分钟** |
| 沟道长度 / 落差 | 20.7 km / 1871 m |
| 视摩擦角 μ_E | 0.0905（5.2°） |
| Voellmy μ | 0.0057（ξ=1000、h=8） |

**一句话**：碎屑流沿 20.7 km 沟道运移、17 分钟抵达口岸段；但口岸台地高出沟底 104 m，模型判定其不被淹没——若实际灾害发生在台地，需要额外的漫流/改道解释。

## 五、必须写进论文的局限

1. **面积不是模型输出**：它由"高出沟底 5 m"阈值控制，体积从 2.5→12.5 ×10⁶ m³ 面积只从 1.69→1.74 km²；随体积变化的是**水深**（3.5→17.4 m）。
2. **口岸台地不被淹没**：与"口岸重大伤亡"存在张力，需讨论漫流/改道/堤防溃决等 DEM 无法表达的因素。
3. 能量线法不含流速场与冲击力，不能用于承灾体损失评估。
4. 未建模沿途松散物质汇入，也未建模堰塞湖溃决。
5. 30 m DEM 低估沟道深度。
