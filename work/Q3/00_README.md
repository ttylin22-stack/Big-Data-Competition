## 一、30 秒结论

| 结论 | 数值 |
|---|---|
| 触发时刻 95% 区间 | **2026-08-06 ~ 2026-08-26**（中位 08-19，宽 20 天） |
| 事件日位置 | 区间内，第 **98 百分位** |
| 自洽性检验 | **5/5**，平均区间宽 **42 天** |
| 沟道长度 / 落差 | **20.7 km** / 1871 m（H/L = 0.090） |
| 传播时间 | **17.0 分钟**（参数集合 9.4–16.2） |
| 预警提前量 | 20 天（区间下界）或 7 天（中位） + 9–16 分钟 |

**一句话**：模型能给"8 月中到 9 月底"这个窗口，给不了"哪一天"；5/5 的"覆盖率"是内部一致性，不是预测能力。

## 五、必须写进论文的局限

1. **区间不是频率学置信区间**，是参数不确定性集合。
2. **μ 与 ξ 不可分离识别**：固定 ξ 才能定 μ；ξ=1000/2000/3000 对应 μ=0.006/0.017/0.025、时间 17.0/13.3/11.6 分钟。
3. **样本截断**：触发集合丢弃 41%（达不到高 H_c），传播集合丢弃 27%（到不了口岸），两者都让区间偏窄。
4. **自洽性 ≠ 覆盖率**：观测日就是模型自己的 70% 融水日。
5. 未补卫星遥感与天气预报数据。
