## 五、必须写进论文的局限

1. **区间不是频率学置信区间**，是参数不确定性集合。
2. **覆盖率不可识别**：只有一场带日期的事件，历史 84 个灾点只有成像时间；5/5 是内部一致性，不能写成"覆盖率 100%"。
3. **μ 与 ξ 不可分离识别**：固定 ξ 才能定 μ；ξ=1000/2000/3000 对应 μ=0.006/0.017/0.025、时间 17.0/13.3/11.6 分钟。
4. **样本截断**：触发集合丢弃 41%（达不到高 H_c），传播集合丢弃 27%（到不了口岸），两者都让区间偏窄。
5. **物源储量是潜在上限**：1–3 m 可动层厚与 10%–30% 启动比例都是假设，未用实测厚度约束。
6. **本沟比降低于 84 条短沟的 25 分位**（0.090 vs 0.175）：本沟属长沟谷—冰川型，与短陡沟样本不在同一适用域，论文需说明。
7. 未补卫星遥感与天气预报数据。
